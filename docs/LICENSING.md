# Licensing decisions remain open

No blanket open-source, Creative Commons, or other license is applied to this repository by alpha v0.1. Public availability does not itself grant a reuse license.

Future decisions may treat these separately:

- Analytical code and reproducibility helpers (`research-projects/`, `scripts/`).
- Original research publications (`research/publications/`).
- Original program materials (`programs/resources/`, approved downloads).
- Public website text and visual assets (`assets/`, public pages).

Review authorship, permissions, original TSP materials, and third-party obligations before selecting licenses. Dependency tooling and packages retain their own upstream licenses; this document does not alter them. No research dataset is redistributed in this alpha.
