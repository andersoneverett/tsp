# Unpublished working material

Keep unpublished public-facing content here until reviewed. This directory is excluded by the explicit render allowlist in `_quarto.yml`, and is never a public download directory. Templates also start with `draft: true` as a second safeguard.

**This repository is public when published. Exclusion from the website does not make files confidential.** Never commit participant data, private records, secret credentials, unapproved identifiable stories, or material without appropriate permissions. Use approved secure storage outside this repository for sensitive work.

To publish, copy a reviewed document to the appropriate content directory as `index.qmd`, replace all template prompts, set a real date and author, and remove `draft: true`. See EDITING-GUIDE.md.
