# Future community program evaluation

Status: planning only; no participant data or findings.

Questions: event implementation, facilitator experiences, access barriers, resource needs, youth decision-making, project outcomes, and local adaptations. Findings should support revisions to resources and inform policy questions with appropriate limits.

Before beginning, copy and adapt the national-service research-plan.md and data-dictionary.csv templates. Define the purpose and proportionate measures with youth and local partners; distinguish process evaluation from outcomes and causal claims. Establish ethical review as needed, safeguarding, consent and assent, secure storage, access, retention, and disclosure rules. Do not collect participant information using this repository or public issues.

Use the national-service directory pattern for nonconfidential analytical code and documentation when a real evaluation begins. Do not add speculative datasets or extensive infrastructure. Public feedback should omit identifying details; confidential feedback requires a secure route outside GitHub.
